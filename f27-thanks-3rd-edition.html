致谢：第 3 版

Technical Reviewers & Acknowledgments for the 3rd Edition

第 3 版技术审校

M

Marc Loy

技术审校

Marc 很早就在 Sun Microsystems 做 Java 培训（向 HotJava 致敬！），从此再没回头。他写过若干本早期 Java 书和培训课程，其间与美国、欧洲、亚洲的各类公司合作。最近他为 O'Reilly 写了《Smaller C》，并合著了《Learning Java》第五版。Marc 目前住在俄亥俄州，是一名软件开发者与创客，专长于微控制器。

A

Abraham Marin-Perez

技术审校

Abraham 是 Java 程序员、顾问、作者和公开演讲者，在多个行业有十余年经验。他原籍西班牙瓦伦西亚，职业生涯大部分在伦敦度过，与 JP Morgan、英国内政部等机构合作，且常与 Equal Experts 协作。想到自己的经历可能对别人有用，他成了 InfoQ 的 Java 新闻编辑，写了《Real-World Maintainable Software》，并合著了《Continuous Delivery in Java》。他也参与运营伦敦 Java 社区。Abraham 永远是个学习者，目前正在攻读物理学学位。
