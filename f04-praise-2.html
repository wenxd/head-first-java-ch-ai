Praise for Head First Java, 3rd Edition

「我真希望自己学 Java 的时候就听说过这本书！如果你想用有趣、幽默、迷人的方式学 Java（谁知道这居然可能？），尤其是如果你像我一样没有传统的计算机科学背景，那这本书绝对是为你写的。我从来没有对一本编程书笑出声过。它写得聪明、机智、抓人、互动性强、好跟，而且极有教育价值。」

Grace Jansen，IBM 开发者布道师

「如果你刚刚踏上学习 Java 编程的旅程，你会面对铺天盖地的书和课程，它们都承诺把你送到目的地。问题是大多数只盯着技术信息，让你不停地问：『到了吗？』《Head First Java》走的是完全不同的路，它让学习这场冒险既有娱乐性又有教育性。用一群狗组成的数组、代码池拼图、五分钟小谜案，还有『削尖你的铅笔』（谁能想到编程还需要铅笔？），这本书让学习变得好玩，同时确保你吸收所有必需的细节。我真希望我开始学 Java 时它就已经存在！」

Simon Ritter，Azul 副 CTO、Java Champion

「这本书从不让人失望。我至今记得大学早期读它的日子，很高兴看到这个改进版。它组织得非常好，英文简单易懂，代码示例清楚。我把它强烈推荐给每一位 Java 开发者。」

Nelson Djalo，科技创业者，Amigoscode.com 学习平台与 Amigoscode YouTube 频道创始人

「我儿子想学 Java 时，我让他读的第一本书就是《Head First Java》。原因很简单：我知道那些好玩的漫画能抓住他的注意力，这是我见过的任何 Java 书都做不到的。读《Head First Java》更像在操场上玩，而不是被困在教室里。」

Kevin Nilson，Google 软件工程师、硅谷 Java 用户组负责人

「我只能嫉妒今天想学 Java 的程序员，因为他们有这本好书。我二十年前学 Java，那过程相当无聊。但这本书永远不会让你无聊。我从没见过哪本 Java 书里有一场 Java 编译器和虚拟机的对决。太震撼了！」

Tagir Valeev，Java Champion、JetBrains IntelliJ IDEA 技术负责人

「大约二十年前，我还是个刚进 Java 世界的初级开发者，读了《Head First Java》第一版；二十年后，第三版依然让我惊叹。这期间变了很多，包括人们讲教程的方式。《Head First Java》第三版是今天那些优秀视频材料的合格替代品：它让学习者——无论初级还是资深——快速抓住概念，既不迷失在细节里，也不把材料讲浅，还给出了足够正确的延伸阅读线索。我尤其喜欢 stream、并发和 NIO 那几部分。」

Michael Simons，Java Champion、Neo4j 工程师，《Spring Boot Buch》作者

「如果你想用 Java 开发软件，这本书就是为你写的。《Head First Java》设计了大量直白而优雅的例子，帮读者理解并学会如何用 Java 造软件。对任何想成为 Java 程序员的人来说，这是一本极好的第一本书。」

Sanhong Li，阿里云
