最后几件需要知道的事

Last-minute things you need to know

这是一段学习经历，不是一本参考书

我们刻意剔除了所有可能妨碍「学当时那件事」的东西。而且第一次读的时候，你必须从头开始——因为这本书对「你已经看过什么、学过什么」是有假设的。

我们用的是简化的、类 UML 的图

如果真用标准 UML，你会看到一些看起来像 Java、但语法根本不对的东西。所以我们用了一个简化版 UML，它不会和 Java 语法打架。如果你本来不懂 UML，那你也不用担心要同时学 Java 和 UML。

我们不管你自己代码的组织与打包

在这本书里，你可以专心学 Java，不必为开发 Java 程序时那些组织性、管理性的细节焦虑。在真实世界里，你确实需要知道并使用这些细节；但既然构建和部署 Java 应用通常依赖 Maven、Gradle 这样的第三方构建工具，我们假设你会单独去学它们。

章末练习是必做的；谜题是选做的

答案都在每章末尾。关于谜题，有一件事你得知道——它们就是谜题。逻辑谜题、脑筋急转弯、填字游戏那一类。练习是为了帮你把学到的东西练熟，你应该全部做完。谜题是另一回事，其中有些按谜题的标准来说相当有挑战性。这些谜题是给「谜题爱好者」准备的，你大概已经知道自己是不是。如果你不确定，我们建议你试几个；但不管怎样，解不出来、或者实在懒得花时间解，都别灰心。

「削尖你的铅笔」练习并不是都有答案

至少书里没印。其中有些本来就没有标准答案；至于其余的，这类活动的一部分学习价值，就在于由你自己判断答案对不对、什么时候对。

代码示例尽可能精简

为了弄懂那两行关键代码，却要在 200 行里跋涉，是很令人沮丧的。本书大多数示例都放在尽可能小的上下文里，好让你要学的那部分清清楚楚。所以别指望这些代码健壮，甚至别指望它完整——那是你读完这本书之后的作业。书里的示例是专门为学习而写的，并不总是能完整运行。

关于标记：带「练习」（跑鞋）标志的活动是必做的——如果你是认真想学 Java，别跳过。看到「谜题」标志，说明这个活动是选做的；如果你不喜欢绕来绕去的逻辑或填字游戏，你也不会喜欢它们。
