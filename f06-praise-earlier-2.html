Praise for earlier editions of Head First Java

「读《Head First Java》，你会重新体验学习的乐趣……对于喜欢学新编程语言、又没有计算机科学或编程背景的人，这本书是珍宝……它让学习一门复杂的计算机语言变得好玩。」

Judith Taylor，俄亥俄东南 Macromedia 用户组

「想学 Java？不用再找了：欢迎来到第一本 GUI 化的技术书！这套执行得完美、开创性的版式，提供了其他 Java 教材根本给不了的好处……准备好踏上一段真正非凡的 Java 之地之旅吧。」

Neil R. Bauman，Geek Cruises 船长兼 CEO

「我对这本书里的小故事、带注释的代码、模拟面试和大脑练习上了瘾。」

Michael Yuan，《Enterprise J2ME》作者

「《Head First Java》给 O'Reilly 那句『总有一本 O'Reilly 适合你』赋予了新含义。我买它，是因为好几位我敬重的人用『革命性』来形容它，说它对教科书的做法彻底不同。他们说得对（现在也对）……O'Reilly 一如既往地采取了科学而周详的做法。结果是：好笑、不敬、切题、互动、精彩……读这本书就像坐在会议的讲者休息室里，向同行学习——并与他们一起大笑……如果你想真正理解 Java，去买这本书。」

Andrew Pollack，www.thenorth.com

「这东西好得让我想哭！我震惊了。」

Floyd Jones，BEA 高级技术文档工程师／泳池小弟

「感觉像有一千磅的书刚从我的脑袋上被搬走了。」

Ward Cunningham，Wiki 发明者、Hillside Group 创始人

「我笑了，我哭了，我被感动了。」

Dan Steinberg，java.net 主编

「我的第一反应是笑到在地上打滚。等我爬起来，才发现这本书不仅技术上准确，还是我见过的、最好懂的设计模式入门。」

Timothy A. Budd 博士，俄勒冈州立大学计算机科学副教授，著有十余本书，包括《C++ for Java Programmers》

「正是我们每个人心里那个技术宅、随性又酷的古鲁程序员该有的调子。它是实用开发策略的恰当参考——让我的脑子转起来，又不必在教授腔的陈词滥调里跋涉。」

Travis Kalanick，Scour 与 Red Swoosh 创始人、MIT TR100 成员
